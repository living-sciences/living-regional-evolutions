# Unemployment cross-section notes

LAUS reconstructs state unemployment only for 1976-1990.

- **1985_on_1975 (C6)**: earlier endpoint 1975 is pre-1976 -> NOT reconstructable. Nearest available analogue reported as **1986_on_1976**.
- **1990_on_1970 (C7)**: earlier endpoint 1970 is pre-1976 -> NOT reconstructable. Nearest available analogue reported as **1990_on_1980**.
- avg-unemployment-vs-employment-growth (Fig 6) and avg-unemployment-vs-wage (Fig 10) run on 1976-1990. Fig 10 uses relative per-capita income as the wage proxy (manufacturing AHE not reconstructable).
