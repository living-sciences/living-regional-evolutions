# Univariate model notes

- Employment: AR(4) in Delta(relative employment), state FE, 1952-1990. sum phi = 0.347; implied level plateau = 1.531.
- Unemployment: AR(2) in level of relative unemployment, state FE. The paper used 1972-1990; LAUS only reconstructs state unemployment from 1976, so the estimation window is **1978-1990** (2 lags off a 1976 start). This shortened window is a documented consequence of the pre-1976 data gap.
- Wage: AR(4) in level of relative wage, state FE, 1952-1990. Manufacturing production-worker AHE is not reconstructable; **relative per-capita income is used as the proxy** for the wage process.
